# 🐕 台灣運彩「瘋狗流」決策系統

> **核心設計理念**：
> 本系統的目標不是自己成為最厲害的運動預測 AI，而是自動蒐集現有最好的情報資訊，幫你在指定 **10～500x** 目標下快速找到值得研究的組合，同時永遠把每週實際風險控制在 **NT$ 200**。

每次打開程式，只需回答三個問題：
1. **① 今天有什麼可以玩？** —— 自動分析主要運動賽季，亮燈顯示今日有盤賽事。
2. **② 我想玩幾倍，哪些組合值得看？** —— 指定 10x ~ 500x 賠率，透過 **Signal Hub** 交叉比對盤口、大神、社群與開源模型情報，產生串關組合。
3. **③ 我這週還有多少錢可以玩？** —— 嚴格執行每週 NT$ 200 娛樂預算，贏錢自動鎖入「獲利保留池」，絕不隨意吐回。

## 🚀 快速啟動

目前策略為 `v2.0-research`（2026-10-12）。模型概率仍是未校準估計；HIGH 代表情報支持程度，不能換算固定勝率。只有市場資料時會標示「市場基準」，信賴區間與保守 EV 保持未知。

開發環境使用 CPython 3.11 Windows；直接與間接依賴版本保存在 `requirements-lock.txt`，專案宣告在 `pyproject.toml`。若需另建環境，先安裝鎖定依賴：

```powershell

```

主頁「記錄已購買注單」只更新本機帳本。搜尋、畫面與記錄都使用同一資料核對：盤口須在 15 分鐘內、尚未開賽、時間含時區、玩法與盤線完整。同一提交重試只扣一次；人工歷史補記另行標示。

## 📱 四大核心頁面導覽

### 📖 指標與資料來源說明
從側邊導覽的「指標與資料來源」，或決策台頂部「看懂 EV、賠率、勝率與資料來源」連結開啟。
這個頁面可離線閱讀，包含賠率與打平門檻對照、可互動的 EV／損益試算，以及 Edge、HIGH/MED/LOW、串關命中率、ROI、CLV 與誤差指標的白話解釋。

賠率 2 倍、假設命中率 60% 時，EV = 0.6 × 2 − 1 = +20%；這是依假設計算的長期平均淨報酬，不是 20% 命中率或獲利保證。大神歷史勝率與社群支持率也不能直接當成本場勝率。
盤口、推薦與投票來自玩運彩公開頁或本機快取；EV 和模型命中率由專案計算。來源表只展示本機紀錄，實際推薦證據會列出來源連結、抓取時間、專家原始推牌與模型資料日期，缺失值標示為未知。

### 🔥 ②「瘋狗看盤」—— 10~500倍 情報串關台
1. **今天你想玩幾倍？**
   - 快速切換：`10x ~ 25x (穩健)`、`25x ~ 75x (狂犬)`、`75x ~ 200x (瘋狗)`、`200x ~ 500x (極限 Moonshot)` 或拖曳滑桿。
2. **跨界混串 (Cross-sport)**：
   - 勾選 ☑ **全部混串**，可同時將 MLB + NFL + 足球 + 職棒組合成一發高倍注單。
3. **Signal Hub (情報中心)**：
   - 不假裝知道精確勝率，而是透明展示四大情報來源支持度：
     - **市場盤口**：台彩賠率與市場隱含傾向
     - **大神主推**：公開會員推牌與本場、玩法、盤線配對後的支持數與比例；榜單只發現候選人。
     - **社群大眾**：玩運彩大眾投票佔比（例如 72% 人看好）
     - **開源統計模型**：基於球隊攻守 Elo / Pythagorean 評估
   - 綜合呈現訊號一致度：**HIGH / MED / LOW / INSUFFICIENT_SIGNAL**。strict 需每關至少 2 個有效來源群組，沒有符合者就保持空結果。
4. **組合分類呈現**：
   - 🟢 **共識較高**：平均訊號一致度高、相對扎實的倍率單。
   - 🟡 **比較瘋**：進攻型高倍單。
   - 🔴 **極限 Moonshot**：極限賠率博弈單。

### 💰 ③「資金紀錄」—— 每週 NT$ 200 風控與獲利池
首頁永遠置頂呈現四大核心數字：
```text
💰 本週可玩：NT$ 130
🎯 本週已下注：NT$ 70
🔒 累積獲利保留 (Prize Pool)：NT$ 2,480
💵 本週外部入金：NT$ 0 / 200
```

#### 資金流轉鐵律 (Money Flow)：
```text
             外部現金
                │
                │ 每週最多 200 (不足 200 才補)
                ↓
         ┌─────────────┐
         │ Weekly Wallet│
         │    $200      │
         └──────┬──────┘
                │
              投注
                │
          ┌─────┴─────┐
          ↓           ↓
         輸            贏
         ↓             ↓
         0          Prize Pool (獲利池)
                       │
             新的一週拿 200 回 Wallet
                       │
                       ↓
                    剩餘保留
```
- **贏錢自動鎖定**：中獎派彩全數進入 `Prize Pool`，不會留在錢包變成衝動加碼的籌碼。
- **獲利自動滾存**：每週開始時，優先從 `Prize Pool` 撥款 NT$ 200 至錢包。若獲利池已有 $\ge$ 200 元，**本週外部入金額度歸零，禁止自掏腰包**！
- **嚴防追單**：若獲利池為 0 且本週 200 額度已用光，系統強制鎖定下注，必須等待下週刷新。

## 💾 資料存放與 C 槽 SSD 防磨損機制
 
為防止每 15 分鐘背景排程累積的龐大研究數據（如 `parlay_snapshots.jsonl` >600MB）過度耗損系統 C 槽 SSD 晶片壽命：
- **物理外移**：所有動態資料、快照、日誌與 SQLite 帳本實體儲存於 `F:\Min\Python\Project\SportsLottery_Data`。
- **NTFS Junction 重定向**：專案透過 Windows 原生交會點（Junction），將 C 槽的 `data/` 透明重定向至 F 槽。
- **零磁區寫入**：所有高頻快照與日誌的物理寫入完全落在 F 槽，**C 槽維持 0 寫入**。
- 詳細架構請參閱 [docs/STORAGE_AND_SSD_PROTECTION.md](docs/STORAGE_AND_SSD_PROTECTION.md)。
