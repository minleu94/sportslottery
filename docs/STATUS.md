# 目前狀況

最後確認：2026-11-03

Sportslottery 目前作為台灣運彩研究與本機注單記錄工具維護。應用程式版本為 2.4.0；策略版本 v2.0-research 是獨立的研究規則標記。

repo 同時保留 Streamlit 桌面版與 FastAPI／React 開發介面；目前 GitHub Release 工作流程打包 Streamlit 桌面版，啟動網址為 http://localhost:8501。

## 已知限制

- 模型機率尚未完成前瞻實證校準，不能據此宣稱預測優勢、正期望值或穩定獲利。
- HIGH、MED、LOW 表示情報支持程度，不對應固定勝率。
- 資料來源、賽事覆蓋和更新時效會變動；文件中的來源能力不代表每次執行都能取得即時資料。
- 離線測試只驗證固定 fixture、模擬服務及本機程式契約；不代表已取得當日真實國際盤、成功配對賽事或完成實際賽後結算。
- 系統不會代替使用者向台灣運彩下單。使用者須自行核對盤口並決定是否投注。

目前狀況只保留仍有效的事實；已完成改動見[變更紀錄](../CHANGELOG.md)，長期規則見各規格文件。
