# 手機版登入與個人設定介面修正

更新日期：2026-10-29

## 修正範圍

- 登入頁的登入、快速註冊、變更 PIN 功能在窄螢幕上擠成多行，不容易看出是三個分開的選項。
- 個人設定頁的編輯設定、管理玩家、新增玩家分頁標題太長，手機上難以辨認。
- 側欄與說明展開器使用 Material Symbols 字型圖示；部分手機瀏覽器沒有載入該字型時，會把 `double_arrow_right`、`arrow_right` 當文字顯示，撐開按鈕並壓到旁邊的內容。
- 長說明展開器標題在手機上換行時，文字與箭頭間距不足。

## 介面調整

- 手機版分頁改為垂直排列的選單卡，每個選項占滿內容寬度，至少 48px 高；選取狀態使用底色與左側色條提示。
- 登入頁分頁改用「登入｜已有帳號」、「註冊｜建立帳號」、「變更 PIN｜已有帳號」等短標題。
- 個人設定分頁改用「編輯我的設定」、「管理玩家」、「新增玩家」等短標題。
- 側欄控制與展開器箭頭改用系統字型符號，並限制圖示容器尺寸；展開器文字可自然換行，不再被圖示文字擠壓。
- 維持頁面安全區留白，讓手機瀏覽器工具列與頁面內容分開。

## 手機驗收步驟

1. 重新啟動 Streamlit／LINE 服務，讓新介面載入。
2. 在手機直向開啟網站，確認側欄控制顯示為箭頭，且頁面不出現 `double_arrow_right` 或 `arrow_right` 字樣。
3. 登入頁確認三個功能以獨立、直向選單卡顯示；分別切換登入、註冊與變更 PIN，確認對應表單內容正確。
4. 登入後開啟「個人設定」，確認編輯、管理、新增玩家選項分開顯示。
5. 展開 PIN 指南與 LINE 指令說明，確認長標題正常換行，箭頭和文字不互相遮擋。
