# 第二輪改進：完整目標與驗收

使用者要求：「你幫我全部都依序搞定阿，用 luna subagent 幫你實作你最後檢查」。沿用三個固定 Luna；主代理負責審查、接線、真實資料核验與最終驗收。上輪結果報告保留為歷史記錄，不能當成本輪完成證明。

## 順序與固定 ownership

1. **大神解析** — expert_sources：明確台彩 DOM／市場上下文、唯一盤線；混合玩法、相反方向、國際盤與部分贏輸比例保留 raw 診斷而不投票。保存的 aa5220 真實 HTML 不得再變成「大1」。主代理驗 known-date 也不能繞過拒絕，普通合法 ML／讓分／大小仍可用。
2. **實驗成績隔離** — wallet_integrity：identity 綁策略、內容與配置 hash／protocol，所有指标選明確實驗；缺身份舊資料列為參考而不混算。重試去重、結果衝突排除、N 與事件數分開，模型誤差與市場同批比對。主代理接 snapshot、影子資料、UI、週報與export並驗hash保護。
3. **跨運動自動結算** — settlement_search：補主頁候選實際聯盟（MLB、足球 EPL/UCL、NBA/WNBA、NFL、NPB/CPBL/KBO）的可信來源與結算。原始 response／URL／HTTP／時間／SHA 證明 schema；同隊／league／時間／provider ID 唯一配對。soccer 90分鐘、延賽、取消、提前結束與未知比分不可造結果。主代理補身份與規則；coverage 必須可見，不以整批 unsupported 代替實作。
4. **模型驗證** — wallet_integrity 完成第2後沿用：真實歷史比分／盤口，以時間切分、訓練／調參／最終測試分開；模型、目前融合估計、市場基準在同批事件比較 Brier、Log loss、命中率、ROI。主代理核驗原始資料及重新計算關鍵結果。未知盤口不能捏造；外國 bookmaker 歷史研究與台彩前瞻資料清楚分開。產出可重跑 CLI、逐事件預測／來源hash／排除audit、可讀報告與模型驗證頁。
5. **主畫面易讀** — expert_sources 完成第1後沿用 UI helpers；主代理 app：先顯示資料完整性／有效支持數／打平門檻，詳細模型與 EV 展開；來源解析拒絕、實驗身份、跨運動結算coverage、模型驗證結果都有入口。低餘額／空資料／過期／零樣本保持未知且操作清楚。隔離 AppTest + 瀏覽器視覺驗證，保留帳本 gate 與提交去重。
