# 朋友安裝指南

本指南只說明如何下載和啟動 Sportslottery。請只從專案的 [GitHub Releases](https://github.com/minleu94/sportslottery/releases) 下載安裝檔，並選擇最新版本中與自己電腦系統相符的檔案。

## Windows

有兩種版本可選：

1. **安裝版**：下載名稱含有 Win11_Setup 的 .exe，雙擊後依畫面步驟安裝。安裝程式可建立桌面捷徑；完成後從捷徑或開始功能表啟動。
2. **免安裝版**：下載名稱含有 Win11_Portable 的 .zip，先解壓縮整個資料夾，再執行資料夾內的 Sportslottery.exe。不要直接在壓縮檔內執行。

目前 Release 安裝包啟動的是 Streamlit 桌面版。啟動後請稍候，程式會在瀏覽器開啟本機介面 http://localhost:8501。若未自動開啟，可手動輸入此網址。

關閉程式時，請關閉啟動程式所開的命令視窗，或在視窗中按 Ctrl+C；只關閉瀏覽器分頁不會停止服務。

## macOS

如果最新版本有提供 macOS .dmg：

1. 開啟下載的 DMG。
2. 將 Sportslottery 拖到「應用程式」資料夾。
3. 從「應用程式」啟動。

如果 macOS 阻止啟動，先停止操作並聯絡提供安裝檔的人確認版本與來源。不要為了啟動程式而關閉整體系統安全防護。

## 更新與資料

更新前先在程式的系統設定頁確認資料存放位置並備份。注單與設定存放在本機，安裝檔不應當作資料備份；解除安裝或更換電腦前，請先確認資料已另行保存。

## 安全與預測說明

若 Windows 或 macOS 顯示安全提示，請先確認安裝檔來自上方的專案 Releases 頁面。無法確認來源時不要繼續安裝，請向提供者核實。
